### Worktree and simulator cleanup

0. Confinement protocol. Verify worktree confinement with `python3 scripts/worktree_protocol.py check`. All linked worktrees must reside strictly inside `<repo_root>/.worktrees/<slug>`; arbitrary external workspace paths are prohibited (principle-boundary-discipline).

1. Snapshot and audit. Record `df -h /`, then run `skills/poteto-mode/scripts/worktree-audit.sh [-b <pr-base-ref>] [--fetch] [repo-path]` from the plugin root (principle-build-the-lever). Without `-b` the `MERGED` column checks `origin/HEAD`, then `origin/main`, then `origin/master`; pass `-b origin/<branch>` when PRs target another branch, and `--fetch` to refresh that base first when it is an `origin/<branch>` (best-effort, opt-in). When no base resolves, `MERGED` is `unknown` and the audit still classifies. It reads paths from `git worktree list`, never hand-typed, since a hand-typed `myrepo-worktrees/x` misses worktrees in external directories (principle-encode-lessons-in-structure). When supported by the host, export `PSTACK_TRANSCRIPTS_DIR` to the host sessions directory. Set `PSTACK_LEFTOVER_PARENT` when isolation clones live outside porcelain. LAST_CHAT `-` is unknown, not idle. It classifies each worktree by size, age, merge state, uncommitted work, PR state, and the newest chat that touched it, then suggests a bucket. The transcript scan is slow, so background it.
2. The bucket is advice, not permission. The pinned and active chats are the real artifact (principle-prove-it-works). Get that set from the user or sidebar and cross-check every candidate. The lever has marked `safe` a worktree the user had pinned, so the pinned set wins.
3. Verify usage before deleting. For every `verify-recent-chat` row, or anything you doubt, fan subagents out to read the transcripts and report whether the chat is pinned or ongoing and which worktrees it touches (principle-guard-the-context-window, transcripts are bulk). A pinned chat spawns arena and repro trees into sibling worktrees via background subagents, and those are in use even when their names never hit the sidebar. Pick each subagent's reasoning level and fast or standard speed for the job, per the Subagents section.
4. Pause on irreversible loss. `wip:N` is N tracked uncommitted edits. `scratch:N` represents untracked or ignored files. Untracked state is never disposable by default, so inspect the files, recover what is needed, and require explicit operator confirmation before deletion. Registered worktrees are removed without force, so any uncommitted state stops deletion. Per Autonomy, clean and merged and not-in-use proceeds. Untracked content, `wip`, unpushed commits, and in-use pause.
5. Prune the confirmed set. After confirmation, run `skills/poteto-mode/scripts/worktree-drop.sh --repo <primary> --dry-run --expect-registered N --expect-leftover N` to list the classified set. N is snapshot-drift, not the delete set. Then `--apply` with the same integers plus each confirmed path as repeated `--path`. Do not copy N from the audit table as confirmation. Pass `--leftover-parent` when the audit used `PSTACK_LEFTOVER_PARENT`. Do not fuse delete into the audit. Branch refs survive, so no commits are lost. Confirm with `df -h /` and re-list.
6. Simulators and other reclaimers. Simulators are usually the next-biggest win. `xcrun simctl --set testing delete all` (XCTestDevices clones), `xcrun simctl delete unavailable`, and `xcrun simctl runtime list` then `runtime delete <id>` for old runtimes. More when needed: Xcode `DerivedData` and `iOS DeviceSupport`, `~/Library/Application Support/Cursor` (`state.vscdb.backup`, and `snapshots/roots/<root>` where a `<root>` named for a folder you opened as a workspace balloons), package caches (pnpm, uv, brew, yarn). Clear only caches the user has not said to keep.

This is the one playbook that deletes user state with no code review to catch a slip, so the gates above are the review.

**Reply:** `df -h /` before and after with space reclaimed, the worktrees pruned, and a one-line reason for each held back (in-use by which chat, or uncommitted work).
