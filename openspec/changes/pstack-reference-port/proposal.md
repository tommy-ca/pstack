## Why

Official pstack is poteto's engineering philosophy, not a Cursor-only bag of tools. Ports fail when they copy `Task` fields instead of the 21 principles, 22 playbook intents, and one router. We need a reference page that names those layers so another host or domain can port the core.

## What Changes

- `docs/guide/12-porting.md`.
- Spec `pstack-reference-port`.
- Guide index item 12.

## Capabilities

### New Capabilities

- `pstack-reference-port`: philosophy, three layers (core / host map / domain packs), port recipe. This Grok tree is the reference implementation of the host-map step.

### Modified Capabilities

None.

## Impact

`docs/guide/12-porting.md`, `openspec/changes/pstack-reference-port/`.
