# pstack-playbooks delta: OMC/OMX method composition

## ADDED Requirements

### Requirement: Canonical pstack methodology is not replaced by native modes
OMC's workflow registry and OMX's mode policy MUST map into canonical pstack intent, leaf skills and named playbooks without introducing a second authoritative methodology registry. Mode aliases and deprecated routing paths MUST be classified as adaptations/gaps, never silently assumed to be equivalent.

#### Scenario: OMC autopilot and pstack orchestrate both match a request
- **GIVEN** the user requests work spanning many sessions
- **WHEN** methodology is selected
- **THEN** pstack's canonical route determines the long-horizon playbook
- **AND** OMC may execute bounded phases while the host owns the program.

### Requirement: Swarm, Arena and Interrogate are composed evidence contracts
Swarm MUST account for required slices and dropout; Arena MUST freeze rubric, isolate candidates and reverify the graft; Interrogate MUST use independent reviewers, preserve disagreements and never auto-apply changes. A native multi-agent Team command MUST NOT itself claim these compositions passed.

#### Scenario: native team completed but a reviewer used shared context
- **GIVEN** a team returns successful completion
- **WHEN** Arena or Interrogate independence is required
- **THEN** the reviewer independence predicate remains failed or untested
- **AND** source reports do not replace a fresh independently observed review.

### Requirement: Verification and shipping remain exact-revision
Long-horizon Orchestrate MUST drain completions as events, carry standing orders across resumes, and maintain a verified integration frontier. A native task completion, plan ledger checkpoint or structurally valid evidence file MUST NOT pass program acceptance without checking the real artifact and relevant integration base.

#### Scenario: worker result passes but branch is rebased
- **GIVEN** an independently verified result describes an earlier patch/revision
- **WHEN** branch changes materially
- **THEN** affected acceptance evidence is invalidated
- **AND** Shipping revalidates before landing.
