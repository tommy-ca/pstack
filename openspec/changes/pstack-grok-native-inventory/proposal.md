## Why

pstack already maps spawn, join, `/loop`, and skills. grok 1.0.13 also ships plan mode, goal mode, workflows, memory, `grok -p`, `grok --worktree`, clone, MCP, hooks, LSP. Without an inventory, ports invent wrappers. We need adopt/skip/gap in a guide.

- `docs/guide/13-grok-natives.md`.

- Guide index item 13.

None.
