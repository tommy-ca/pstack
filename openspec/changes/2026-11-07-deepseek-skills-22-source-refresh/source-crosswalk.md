## Priority for the new six
1. **Reusable only as a review lens:** Cordis lifecycle audit becomes service/resource ownership invariants, not a Cordis implementation skill. Use controlled interleavings and quiescent teardown evidence.
2. **Reusable with domain predicate:** session projection applies only to event-sourced/restorable state. Replay is deterministic, synchronous and side-effect-free; snapshots and incremental replay must agree; service APIs own reads.
3. **Reusable as bounded PR discipline:** description communicates externally observable behavior, exact running checks, migration impacts and any required AI attribution without imposing DSH's template or Chinese language.
4. **Optional UI:** responsive width, touch/hover, focus and action reachability are meaningful only to UI projects; preserve host/product breakpoints, not 390px as a universal constant.
5. **Optional artwork:** evaluate images and assets in their actual product context; DeepSeek icon design metrics and brand treatments stay local.
6. **Host-specific:** CUA signing and keychain automation require macOS and explicit authorized setup; default PStack never generates certificates or touches user credentials.
