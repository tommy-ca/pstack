## Why

01-setup installs the plugin but does not teach grok-native pstack: `pstack:<role>`, depth 1, `/loop` as a new turn, skill order, Benny slash, no plugin hooks. Operators bounce between HARNESS and 13-grok-natives. The quickstart should carry that mental model.

## What Changes

- `docs/guide/01-setup.md` section How grok-native pstack works.
- Guide README one paragraph.
- Spec `pstack-quickstart`.

## Capabilities

### New Capabilities

- `pstack-quickstart`: first-session page names MAX_SUBAGENT_DEPTH, Skill order, pstack:independent-verifier, scheduler_create.

### Modified Capabilities

None.

`docs/guide/01-setup.md`, `docs/guide/README.md`.
