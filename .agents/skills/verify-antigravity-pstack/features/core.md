# Core Feature: Antigravity PStack Verification

## Sub-features
- Plugin manifest and model catalog projection
- Antigravity slash commands synchronization
- Four-plane portable verification doctor checks
- Evidence receipt recording and freshness validation

## How to get to it (user POV)
Run the verification driver doctor check from workspace root.
Execute `bash .agents/skills/verify-antigravity-pstack/scripts/driver.sh doctor`.

## Driving it with Antigravity
Drive verification across projection, unit tests, and portable evidence planes.
Execute `bash .agents/skills/verify-antigravity-pstack/scripts/driver.sh drive`.

## Gotchas
The active host profile must exist at `profiles/antigravity.json`.
Dependencies must be installed in the virtual environment.
Stale receipts require running static refresh before validation.
